# Telegram-бот техподдержки

Бот для игрового проекта: подключение двухфакторной защиты (TOTP), связь с оператором поддержки и восстановление пароля.

## Возможности

- 🔐 Подключение двухфакторной аутентификации (Google Authenticator, Authy и др.) с QR-кодом
- 🎫 Тикеты: игрок выбирает тему и описывает проблему, в группе операторов появляется карточка тикета с номером, статусом и кнопками «Взять в работу» / «Закрыть»; ответы оператора возвращаются игроку
- 🔑 Восстановление пароля: временный пароль выдаётся только Telegram-аккаунту, привязанному к игровому, с проверкой кода 2FA и лимитом запросов
- Меню с картинкой и кнопками-ссылками (сайт, форум, магазин)

## Настройка

Переменные задаются в панели хостинга (вкладка Environment). Токен в репозиторий не добавляйте.

| Переменная | Описание |
|-----------|----------|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `SUPPORT_CHAT_ID` | ID группы операторов (узнать командой `/chatid` в группе) |
| `SUPPORT_THREAD_ID` | (необязательно) ID темы-очереди, куда приходят новые тикеты; узнать командой `/chatid` внутри темы |
| `TICKET_TOPICS` | `1` (по умолчанию): отдельная тема на каждый взятый тикет; `0`: отключить |
| `PROJECT_NAME` | название проекта |
| `SITE_URL`, `FORUM_URL`, `SHOP_URL` | ссылки для кнопок; пустые кнопки не показываются |
| `BANNER_PATH` | путь к картинке меню, по умолчанию `banner.jpg` |

## Группа поддержки и тикеты

1. Создайте группу, добавьте в неё бота и операторов, включите **Темы** (Topics) в настройках группы.
2. Сделайте бота администратором с правами **«Управление темами»** и **«Удаление сообщений»**.
3. Создайте тему «Очередь» и отправьте в ней `/chatid`: бот пришлёт ID группы (`SUPPORT_CHAT_ID`) и ID темы (`SUPPORT_THREAD_ID`).
4. Игрок создаёт тикет: «Связь со службой поддержки» → тема → описание (можно со скриншотом).
5. Новый тикет приходит в «Очередь» карточкой с кнопками «Взять в работу» и «Закрыть».
6. **Когда оператор берёт тикет**, для него создаётся отдельная тема «#N · категория · игрок». Туда переезжают карточка и переписка, из очереди они исчезают. В теме достаточно просто писать, сообщения оператора уходят игроку.
7. **Когда тикет закрыт** (оператором или игроком), тема со всей перепиской удаляется из группы. В базе остаются только номер, категория, статус и оператор.
8. Пока тикет открыт, любые сообщения игрока в личке добавляются в него. У игрока не может быть больше одного открытого тикета.

Если Темы в группе не включены или у бота нет прав, тикеты работают без отдельных тем (всё в одном чате, ответ через «Ответить»). Отключить создание тем можно переменной `TICKET_TOPICS=0`.

Темы тикетов меняются в списке `TICKET_CATEGORIES` в начале `main.py`.

## Важно: подключение к игровому серверу

В `main.py` класс `Backend` работает в демо-режиме на локальной SQLite. Перед использованием игроками замените его методы на запросы к вашей игровой базе или API:

- `get_owner`, `link_owner` — привязка игрового ника к Telegram
- `get_totp`, `save_totp` — хранение ключа двухфакторки
- `set_password` — смена пароля в игре

Привязку ника к Telegram необходимо подтверждать владельцем аккаунта (например, одноразовым кодом из игры или с сайта). В демо-режиме ник привязывается к первому, кто его назвал.

## Безопасность

- Бот никогда не запрашивает текущий пароль.
- Не публикуйте токен бота. Если он попал в открытый доступ, перевыпустите его в @BotFather (`/revoke`).
