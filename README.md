# Telegram-бот техподдержки

Бот для игрового проекта: подключение двухфакторной защиты (TOTP), связь с оператором поддержки и восстановление пароля.

## Возможности

- 🔐 Подключение двухфакторной аутентификации (Google Authenticator, Authy и др.) с QR-кодом
- 👨‍💼 Связь с оператором: сообщения игрока пересылаются в группу поддержки, ответы оператора возвращаются игроку
- 🔑 Восстановление пароля: временный пароль выдаётся только Telegram-аккаунту, привязанному к игровому, с проверкой кода 2FA и лимитом запросов
- Меню с картинкой и кнопками-ссылками (сайт, форум, магазин)

## Запуск

```bash

```

## Группа поддержки

1. Создайте группу и добавьте в неё бота и операторов.
2. Отправьте в группе `/chatid` и впишите полученное число в `SUPPORT_CHAT_ID`.
3. Чтобы ответить игроку, нажмите «Ответить» на любое сообщение бота или пересланное сообщение игрока.

## Важно: подключение к игровому серверу

В `main.py` класс `Backend` работает в демо-режиме на локальной SQLite. Перед использованием игроками замените его методы на запросы к вашей игровой базе или API:

- `get_owner`, `link_owner` — привязка игрового ника к Telegram
- `get_totp`, `save_totp` — хранение ключа двухфакторки
- `set_password` — смена пароля в игре

Привязку ника к Telegram необходимо подтверждать владельцем аккаунта (например, одноразовым кодом из игры или с сайта). В демо-режиме ник привязывается к первому, кто его назвал.

## Безопасность

- Бот никогда не запрашивает текущий пароль.
- Не публикуйте токен бота. Если он попал в открытый доступ, перевыпустите его в @BotFather (`/revoke`).
